# 2048 на Python

Небольшая консольная игра 2048 без сторонних библиотек. Игрок двигает плитки клавишами `W`, `A`, `S`, `D` и объединяет одинаковые числа.

## Возможности

- два размера поля: 4×4 с целью 2048 и 5×5 с целью 4096;
- автоматическое появление новых плиток 2 и 4;
- подсчёт очков и рекорда за текущий запуск;
- отмена последнего хода;
- новая игра без перезапуска программы;
- сообщения о победе и отсутствии доступных ходов;
- проверка команд и корректная обработка `Ctrl+C`/конца ввода.

## Запуск

Нужен Python 3.10 или новее. Внешние пакеты не требуются.

```bash
python main.py
```

Тесты запускаются стандартным модулем Python:

```bash
python -m unittest discover -s tests -v
```

## Структура проекта

- `main.py` — поле, алгоритм движения и объединения, игровой цикл и меню;
- `tests/test_game.py` — тесты движения, слияния, окончания игры и отмены хода.

## Что демонстрирует проект

- **DRY:** все правила движения находятся в одном классе `Board`;
- **KISS:** игра работает в обычном терминале и использует только стандартную библиотеку;
- **SOLID и инкапсуляция:** поле, игровой цикл и настройки разделены по отдельным классам;
- **алгоритмы:** сжатие строк, объединение плиток, поиск доступных ходов и проверка окончания игры;
- **расширяемость:** размер поля и целевая плитка задаются через `GameConfig`.
