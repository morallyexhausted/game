# Night Siege: Last Stand

**Night Siege: Last Stand** — top-down survival shooter на Pygame. Игрок удерживает дом, отбивается от волн зомби, заколачивает окна и старается набрать как можно больше очков.

Игра собрана на основе открытого проекта [Bullet-vs-Dead](https://github.com/noxtikkus-sudo/Bullet-vs-Dead), но в этой версии изменены название, интерфейс и баланс, а также добавлены счёт, статистика убийств, бонус за волну и рывок игрока.

## Управление

- **WASD** — движение;
- **Мышь + ЛКМ** — прицеливание и стрельба;
- **Space** — рывок на 150 пикселей в направлении движения или прицела (перезарядка 2,5 секунды);
- **E** — поставить доску на ближайшее окно;
- **Esc** — пауза / выход назад;
- **W/S или стрелки, Enter** — навигация по меню.

## Особенности версии

- Очки: 10 за каждого зомби и бонус за зачистку волны.
- В HUD отображаются счёт, убийства и состояние рывка.
- Рывок проходит по нескольким коротким шагам и не позволяет проскочить сквозь стену.
- Зомби преследуют игрока через A* pathfinding, а окна можно укреплять досками.
- Есть динамическая темнота, камера, звуки выстрелов, шагов и ударов по баррикадам.

## Запуск

Нужен Python 3.10+.

```bash
python -m pip install -r requirements.txt
python main.py
```

Для Linux без аудиоустройства можно запустить в dummy-режиме звука:

```bash
SDL_AUDIODRIVER=dummy python main.py
```

## Структура

- `main.py` — игровой цикл, меню, HUD, подсчёт очков и состояния игры;
- `player.py` — движение, здоровье и рывок игрока;
- `enemy.py`, `wave_manager.py` — зомби и волны;
- `bullet.py` — снаряды и попадания;
- `map.py`, `navigation.py` — карта, окна, коллизии и A*;
- `sound_manager.py`, `assets.py` — звуки и ресурсы;
- `settings.py` — баланс и визуальные настройки.
