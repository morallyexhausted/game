# 2048 на Python + pygame

Оконная игра 2048 с графическим интерфейсом на `pygame`. Игрок двигает плитки стрелками или клавишами `W`, `A`, `S`, `D` и объединяет одинаковые числа.

## Возможности

- отдельное окно с главным меню;
- два размера поля: 4×4 с целью 2048 и 5×5 с целью 4096;
- автоматическое появление новых плиток 2 и 4;
- подсчёт очков и рекорда за текущий запуск;
- пауза с визуальным затемнением игрового поля;
- отмена последнего хода;
- новая игра и возврат в меню;
- **«Молоток»** — один раз за игру удаляет выбранную занятую плитку и освобождает место;
- управление мышью и клавиатурой;
- сообщения о победе и отсутствии доступных ходов.

## Установка и запуск

Нужен Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python main.py
```

В Windows можно запускать двойным щелчком по `main.py` после установки Python и pygame.

Тесты запускаются стандартным модулем Python:

```bash
python -m unittest discover -s tests -v
```

## Управление

- стрелки или `W/A/S/D` — движение плиток;
- `P` или пробел — пауза / продолжить;
- `U` — отменить последний ход;
- `H` — включить режим молотка, затем нажать на занятую плитку;
- `N` — новая игра;
- `Esc` — вернуться в меню.

## Структура проекта

- `main.py` — игровое поле, алгоритм движения и правила игры;
- `gui.py` — меню, окно игры, кнопки, пауза и обработка событий pygame;
- `tests/test_game.py` — тесты движения, слияния, окончания игры, отмены и молотка;
- `requirements.txt` — единственная внешняя зависимость `pygame`.

## Что демонстрирует проект

- **DRY:** правила движения, объединения и молотка находятся в классе `Board` и `Game`;
- **KISS:** интерфейс состоит из одного окна, меню и понятных кнопок;
- **SOLID и инкапсуляция:** игровая логика отделена от графического интерфейса;
- **алгоритмы:** сжатие строк, объединение плиток, поиск доступных ходов и история состояний для отмены;
- **расширяемость:** размер поля и целевая плитка задаются через `GameConfig`.
