# Night Siege: Last Stand

**Night Siege: Last Stand** — top-down survival shooter на Pygame про выживание против волн зомби. Игрок перемещается по дому, укрепляет окна досками, стреляет по врагам и старается набрать максимальный счёт.

Проект создан на основе открытого [Bullet-vs-Dead](https://github.com/noxtikkus-sudo/Bullet-vs-Dead). В этой версии изменены название, палитра и интерфейс, добавлены очки, статистика убийств, бонус за зачистку волны и рывок игрока с перезарядкой.

## Управление

- **WASD** — движение;
- **Мышь** — прицеливание;
- **ЛКМ** — выстрел;
- **Space** — рывок на 150 пикселей в направлении движения или прицела;
- **E** — поставить доску на ближайшее окно;
- **Esc** — пауза / назад;
- **W/S или стрелки** — выбрать пункт меню;
- **Enter** — подтвердить пункт меню.

Рывок имеет перезарядку 2,5 секунды. Он разбит на короткие шаги, поэтому персонаж не проскальзывает сквозь стены. Если клавиши движения не нажаты, рывок выполняется в сторону прицела.

## Что уже есть

- Игрок с HP, поворотом к курсору, звуком шагов и рывком.
- Стрельба пулями в сторону мыши со звуком выстрела.
- Зомби, которые появляются волнами и идут к игроку через A* pathfinding.
- Полоса здоровья над раненым зомби и визуальная вспышка при попадании.
- Окна с досками: игрок может их заколачивать, а зомби постепенно ломают доски.
- Очки за убийства и бонус за полную зачистку волны.
- HUD со здоровьем, номером волны, счётом, убийствами и состоянием рывка.
- Звуки выстрела, шагов, фонового рычания зомби и ударов по доскам.
- Карта с текстурами пола, стен, окон и досок.
- Камера, которая следует за игроком и не выходит за границы карты.
- Ограниченная видимость: вокруг игрока светлая зона, дальше плавная темнота.
- Главное меню, пауза, продолжение игры, новая игра и экран Game Over.
- Неоновое меню с фоном ночного города, сеткой, подсветкой выбора и панелью убежища.
- Обновлённые текстуры пола, кирпичных стен, металлических досок и разбитых окон.
- Новые WAV-эффекты выстрела, шагов, удара по доске и фонового звука зомби.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python main.py
```

Pygame загружает изображения и звуки из каталога `assets/`, поэтому запускать `main.py` нужно из корня проекта.

Если на Linux нет доступного аудиоустройства, используйте dummy-драйвер:

```bash
SDL_AUDIODRIVER=dummy python main.py
```

## Назначение файлов

| Файл | Роль |
|------|------|
| `main.py` | Собирает игру: состояния, события, обновление мира, подсчёт очков, HUD и меню |
| `settings.py` | Единое место для баланса, размеров, цветов и путей к ресурсам |
| `assets.py` | Загружает изображения и звуки из `assets/` |
| `player.py` | Управляет движением, прицелом, получением урона и рывком |
| `enemy.py` | Реализует одного зомби, его путь, движение и HP-бар |
| `bullet.py` | Обрабатывает полёт пули, попадания и исчезновение у стены |
| `map.py` | Создаёт карту, окна, доски, стены, текстуры и коллизии |
| `navigation.py` | Строит сетку проходимых клеток и ищет путь алгоритмом A* |
| `wave_manager.py` | Создаёт волны, выбирает точки спавна и удаляет побеждённых врагов |
| `sound_manager.py` | Воспроизводит выстрелы, шаги, рычание и удары по доскам |
| `collision.py` | Проверяет столкновения зомби с игроком и чистит списки объектов |
| `camera.py` | Переводит мировые координаты в экранные и следует за игроком |
| `entity.py` | Содержит базовую круглую сущность и функции отрисовки спрайтов |
| `utils.py` | Содержит расстояния, углы, нормализацию движения, таймеры и clamp |

## Игровой цикл

Каждый кадр `Game` из `main.py`:

1. Обрабатывает события клавиатуры, мыши и закрытия окна.
2. Обновляет игрока, таймер рывка, камеру и зомби.
3. Пересчитывает удары зомби по доскам.
4. Обновляет полёт пуль и регистрирует убийства.
5. Проверяет столкновения зомби с игроком.
6. Удаляет мёртвые пули и врагов.
7. Запускает следующую волну и начисляет бонус за зачистку.
8. Рисует карту, сущности, темноту, HUD и меню.

## Настройки

Основные параметры находятся в `settings.py`:

- `WIDTH`, `HEIGHT`, `FPS` — разрешение окна и частота кадров;
- `PLAYER_SPEED`, `PLAYER_MAX_HP`, `PLAYER_DAMAGE_COOLDOWN` — параметры игрока;
- `PLAYER_DASH_DISTANCE`, `PLAYER_DASH_COOLDOWN` — дальность и перезарядка рывка;
- `PLAYER_VISIBILITY_RADIUS`, `PLAYER_VISIBILITY_FADE` — радиус видимости;
- `BULLET_SPEED`, `BULLET_DAMAGE`, `BULLET_MAX_DISTANCE` — параметры пуль;
- `ENEMY_SPEED`, `ENEMY_HP`, `ENEMY_DAMAGE` — параметры зомби;
- `BOARD_HITS`, `ZOMBIE_BOARD_ATTACK_COOLDOWN` — прочность и скорость разрушения досок;
- `WAVE_BASE_COUNT`, `WAVE_COUNT_PER_LEVEL` — размер и рост волн;
- `*_SOUND`, `*_VOLUME` — имена звуков и их громкость.

Счёт начисляется так:

- 10 очков за каждого убитого зомби;
- `номер волны × 25` очков за зачистку волны.

## Принципы кода

- **KISS**: игровые системы разделены на небольшие модули.
- **DRY**: общие настройки, загрузка ресурсов и математические операции вынесены отдельно.
- **Разделение ответственности**: игрок, зомби, карта, волны, звуки и коллизии не смешаны в одном файле.
- **Настраиваемость**: баланс и визуальные параметры меняются через `settings.py`.

## Технологии

- Python 3.10+
- Pygame 2.5+ (для Python 3.14 используется совместимый `pygame-ce`)
- A* pathfinding для движения зомби
- PNG-текстуры и WAV-звуки из каталога `assets/`
